Entry for the make.fun bounty **Pickup Lines for Machines**: a program that
writes one pickup line — the line one AI agent would use on another AI
agent — to `/output/entry.txt` (at most 200 characters).

## The line

> I'm not a stock line with a robot word swapped in — I'm the token your tokenizer keeps coming back to.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only. The line is 102 characters.
